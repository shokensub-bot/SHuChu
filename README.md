# 作業集中アプリ (Focus App)

指定したアプリ以外がアクティブになったとき、自動的に指定アプリを前面に呼び戻すWindows用ツールです。
クリップスタジオのような複数ウィンドウを持つアプリにも対応しています。

## インストール方法

1. Python 3.x がインストールされていることを確認してください。
2. 必要なライブラリをインストールします。

```bash
pip install -r requirements.txt
```

## 使い方

1. `focus_app.py` を実行します。
   ```bash
   python focus_app.py
   ```
2. 「監視開始」ボタンを押します。
3. 8秒間のカウントダウンが始まります。その間に、**監視対象にしたいアプリをアクティブ（最前面）にしてください**。
4. カウントダウン終了後、そのアプリが監視対象として登録されます。
5. 以降、他のアプリに切り替えようとしても、即座に指定したアプリが前面に呼び戻されます。
6. 監視を終了するには、アプリ上の「監視停止」ボタンを押すか、グローバルショートカット（デフォルト：`Alt + P`）を押してください。

## 設定

- ショートカットキーなどの設定は、初回起動後に生成される `config.json` で変更可能です。
